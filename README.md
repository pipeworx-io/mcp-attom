## Quick Start

Add to your MCP client config:

```json
{
  "mcpServers": {
    "attom": {
      "url": "https://gateway.pipeworx.io/attom/mcp"
    }
  }
}
```

Or use the CLI:

```bash
npx pipeworx use attom
```
